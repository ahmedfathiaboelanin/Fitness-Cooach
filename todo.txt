🏋️ Gym Coaching Platform (Frontend Only)

A modern React frontend application for a gym coaching platform where users can browse coaches, view workout programs, track progress UI, and simulate booking personal training sessions.

NOTE:
This project is frontend-only and uses mock data only.
No backend or API integration.

--------------------------------------------------

TECH STACK:
- React (Vite)
- React Router DOM
- Tailwind CSS
- Framer Motion (animations)
- React Hook Form (UI forms only)
- Zustand / Redux Toolkit (optional state management)
- Mock JSON data

--------------------------------------------------

PROJECT STRUCTURE:

src/
